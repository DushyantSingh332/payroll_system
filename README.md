# 💰 Payroll Management System

A **console-based Payroll Management System** developed in **Python** that helps manage employee records and perform payroll calculations. This project demonstrates Python programming concepts, file handling, loops, conditional statements, and data management.

## 📌 Features

- ➕ Add employee records
- 👨‍💼 View employee details
- 💰 Calculate employee salary
- ✏️ Update employee information
- ❌ Delete employee records
- 💾 Store employee data using file handling
- ⚠️ Input validation for accurate record management

## 🛠️ Technologies Used

- Lists
- Loops and Conditional Statements
